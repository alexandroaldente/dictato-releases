# Dictato 0.1.1

Initial local alpha for Apple Silicon Macs.

- Offline Parakeet transcription for mixed Russian and English.
- Hold and toggle dictation modes.
- Configurable global shortcut, microphone, vocabulary, and dictation overlay.
- No transcription history stored by Dictato.
- On first launch, Dictato automatically installs the verified 640 MB local
  Parakeet model. No API key or account is required.

Known limitation: this build is locally signed for development. A public release requires Apple Developer ID signing and notarization.
