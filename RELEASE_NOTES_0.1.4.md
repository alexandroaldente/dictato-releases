# Dictato 0.1.4 Alpha

- Settings now shows verified local-model download progress.
- The recording indicator shows a processing state while a model is preparing;
  it no longer looks like the microphone is already recording.
- Added update discovery: when a newer Dictato release exists, an Update button
  appears beside the installed version and opens the exact GitHub release.
- Fixed the displayed app version to read from the installed bundle.

Apple Silicon Macs only. This Alpha build is not yet notarized by Apple.
