# Dictato 0.1.10 Alpha

## Quiet updates

- Press **Update** inside Dictato when a new version is available.
- Dictato downloads the new build in the background, closes, replaces itself,
  and reopens automatically.
- No GitHub page or browser window opens during the normal update flow.

If Dictato is installed in the protected system-wide Applications folder,
macOS can request the account password to approve replacing the application.
This is the standard macOS protection for apps in that folder.
