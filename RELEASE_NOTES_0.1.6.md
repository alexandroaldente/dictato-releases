# Dictato 0.1.6 Alpha

- Added Russian interface localization with automatic system-language selection.
- Added clear first-run model preparation progress and faster microphone access.
- Added optional compact GigaAM v3 model for Russian dictation; Parakeet remains
  the recommended model for mixed Russian and English.
- Refined model download, removal, sound, shortcut, menu, and recording-window
  behavior.
- Added update discovery: older Dictato versions show an Update button in the
  bottom-left corner of Settings when a newer GitHub release is available.
- A running Dictato clears its own local data when moved to the Trash.

Known limitation: this build is locally signed for development. A public release
requires Apple Developer ID signing and notarization.
