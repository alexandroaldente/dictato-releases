# Dictato 0.1.3 Alpha

- First dictation now requests microphone access before offering the optional
  local-model download.
- This removes the confusing wait where macOS could appear to ignore the
  microphone request while the 640 MB model was downloading.
- Includes all 0.1.2 privacy, model-download confirmation, and About updates.

Apple Silicon Macs only. This Alpha build is not yet notarized by Apple.
