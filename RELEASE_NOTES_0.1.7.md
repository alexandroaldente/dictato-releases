# Dictato 0.1.7 Alpha

Dictato now includes its default local Parakeet model inside the application.

- Ready for Russian and English dictation after installation, without a separate first-run model download.
- The installer is larger, about 640 MB for the included offline model.
- The Models screen no longer shows download progress for the default model.
- GigaAM v3 remains an optional local Russian model and downloads only when selected.

This alpha build is for Apple Silicon Macs running macOS 14 or later. Dictato stores speech processing locally and does not require API keys.
